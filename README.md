# Мониторинг заседаний мировых судей г. Перми (ГАС «Правосудие»)

Telegram-бот, который периодически ищет в открытом портале ГАС «Правосудие»
судебные дела по заданным статьям КоАП у мировых судей г. Перми и присылает
даты судебных заседаний.

## Что делает

- Ищет дела по статьям из `config.yaml` (по умолчанию `12.8`, `12.26`, `20.20`, `6.9`).
- Ограничивает поиск: регион — Пермский край, город — Пермь, тип суда — мировой судья.
- Раз в `poll_interval_minutes` минут обходит выдачу (Playwright, настоящий браузер).
- Присылает в Telegram: **новые** дела и **переносы** заседаний (изменилась дата/время).
- Ведёт базу SQLite, чтобы не дублировать уведомления.

## Что нужно

- Машина/VPS с доступом в интернет к `sudrf.ru` и `ej.sudrf.ru` (из локальной сети
  и с обычного сервера портал обычно доступен).
- Токен Telegram-бота (у [@BotFather](https://t.me/BotFather) → `/newbot`).

> ⚠️ Скрипт вежливо обращается к сайту (случайные паузы между запросами) и рассчитан на
> личное использование. При появлении капчи бот приостанавливается и уведомляет вас.

## Быстрый старт (Docker)

```bash
cp .env.example .env
# отредактируйте .env: впишите TG_BOT_TOKEN и ADMIN_CHAT_ID
docker compose up -d --build
docker compose logs -f
```

`ADMIN_CHAT_ID` можно узнать: запустите бота, отправьте ему `/start` — он ответит вашим chat_id.

## Запуск без Docker

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
playwright install --with-deps chromium
cp .env.example .env   # заполните токен и chat_id
python -m src.main
```

## Отладка скрейпера (на VPS)

Вёрстка ГАС «Правосудие» меняется, поэтому есть режим отладки со скриншотами:

```bash
python -m src.scraper --debug --headful
```

- `--headful` — видно окно браузера (нужен графический доступ/VNC на сервере).
- При сбое в `logs/` сохраняется скриншот страницы.
- Селекторы собраны в словаре `SELECTORS` в `src/scraper.py` — править нужно только там.

## Конфигурация (`config.yaml`)

| Параметр | Описание |
|---|---|
| `articles` | список статей КоАП; совпадение по префиксу (`12.8` → `12.8 ч.1`, `12.8 ч.3`) |
| `region`, `city` | география поиска |
| `court_type` | тип суда (`Мировой судья`) |
| `districts` | `[]` = все участки г. Перми; иначе список номеров участков |
| `lookback_days` | за сколько последних дней искать |
| `poll_interval_minutes` | период опроса |
| `scraper.*` | headless, таймауты, паузы, предохранители |

## Команды бота

- `/start` — приветствие и ваш chat_id
- `/articles` — отслеживаемые статьи
- `/check` — проверить прямо сейчас
- `/status` — статистика
- `/upcoming` — ближайшие заседания
- `/mute`, `/unmute` — выключить/включить уведомления

## Структура

```
config.yaml        конфигурация поиска
.env               секреты (не коммитить)
src/config.py      загрузка config.yaml + .env
src/scraper.py     Playwright-скрейпер ГАС «Правосудие»
src/parsers.py     разбор карточек дел (тестируется без сети)
src/storage.py     SQLite: антидубли, история, настройки
src/bot.py         Telegram-бот и уведомления
src/scheduler.py   периодические проверки
src/main.py        запуск
tests/             юнит-тесты (pytest)
```

pytest -q

## Ограничения

- Скрейпинг зависит от текущей вёрстки портала; при её изменении может потребоваться
  правка селекторов в `src/scraper.py` (есть debug-режим и скриншоты).
- Парсер выдачи проверен юнит-тестами на типовых таблицах/карточках; реальные селекторы
  формы поиска нужно один раз проверить на машине с доступом к `sudrf.ru`.
