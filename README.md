# Поиск судебных дел — мировые судьи г. Перми (ГАС «Правосудие»)

Настольная программа с интерфейсом на **tkinter**: вы вписываете статьи КоАП
(через запятую), нажимаете «Найти» — программа ищет дела у мировых судей
г. Перми на открытом портале ГАС «Правосудие» и показывает список найденных
дел с датами заседаний и ссылками. **Двойной клик по строке открывает карточку
дела в браузере.**

## Что делает

- Поле ввода статей КоАП: `12.8, 12.26, 20.20, 6.9` (см. `config.yaml` как подсказку).
- Поиск ограничен: регион — Пермский край, город — Пермь, тип суда — мировой судья.
- Результаты в таблице: статья, дата/время заседания, участок, номер дела, ссылка.
- Клик по строке (или кнопка «Открыть в браузере») открывает дело в системном браузере.
- Поиск идёт в фоне — окно не подвисает.

## Глубина и объём поиска

- Ищет по всем участкам и по **всем страницам выдачи** (до `max_pages` на участок).
- После прохождения капчи, если на странице есть таблица дел, каждая страница
  разбирается: номер дела, дата, время слушания, участники дела.
- Новые дела **дописываются строками** в Excel-файл `data/cases.xlsx`
  (настраивается в `config.yaml` → `output_excel`). Дубли (номер + дата + время
  заседания) не добавляются повторно, поэтому парсер можно запускать по частям.
- Если таблицы дел на странице нет — она пропускается.
- При серверной ошибке **500** страница автоматически перезагружается
  (`retry_on_500`, `max_500_reloads`) — парсер больше не встаёт до ручной
  перезагрузки.

Кнопка «Открыть Excel» в окне открывает собранную таблицу.

## Требования

- Python 3.11–3.13 (рекомендуется 3.12) с модулем **tkinter** (`python3-tk`).
  Python 3.14 и новее пока не имеют готовых wheel-пакетов для части зависимостей,
  из-за чего pip пытается собирать их из исходников (на Windows нужен MSVC).
- Доступ в интернет к `sudrf.ru`.
- Браузер Chromium для Playwright.

### Установка tkinter

- **Linux (Debian/Ubuntu):** `sudo apt install python3-tk`
- **Linux (Fedora):** `sudo dnf install python3-tkinter`
- **Windows/macOS:** tkinter входит в стандартный Python.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate         # Windows: .venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium

cp .env.example .env              # необязательно
python -m src.main
```

Откроется окно: впишите статьи через запятую и нажмите «Найти».

## Отладка скрейпера

Вёрстка ГАС «Правосудие» меняется, поэтому есть режим отладки со скриншотами:

```bash
python -m src.scraper --debug --headful --articles "12.8,20.20"
```

- `--headful` — видно окно браузера.
- При сбое в `logs/` сохраняется скриншот.
- Селекторы собраны в словаре `SELECTORS` в `src/scraper.py` — править нужно только там.

## Ошибка «403 Доступ запрещен»

Сайты участков (`NN.perm.msudrf.ru`) отдают `403`, если запросы идут без окна
(headless) или с «серверного» IP. Решения:

- Запускать в видимом браузере: `headless: false` в `config.yaml` (значение по
  умолчанию) или флаг `--headful`.
- Запускать со своего домашнего ПК, а не с сервера/VPN.
- Если 403 сохраняется — подождать 10–15 минут и повторить.

## Распознавание капчи

Сначала капчу пробует локальный OCR (`ddddocr`). Если он не справляется,
подключается vision-модель (по умолчанию — Yandex Cloud, `qwen3.6-35b-a3b`).

- **Капча состоит только из русских букв (кириллица).** Латиница и цифры в
  распознанном коде отбрасываются. `ddddocr` обучен на латинице, поэтому для
  русской капчи он обычно бесполезен — vision-модель подключается сразу.

- Модель **обязана поддерживать изображения** (vision/мультимодальная). Текстовая
  модель картинку не видит — вернёт пустой ответ.
- Ключ: `VISION_API_KEY` и `YANDEX_FOLDER_ID` в `.env`; в `config.yaml` —
  `captcha_vision_auth_scheme: "api-key"`, `captcha_vision_base_url` и модель
  вида `gpt://<folder_id>/<vision-модель>/latest`.
- `captcha_vision_max_tokens` даёт запас токенов reasoning-моделям, иначе
  `content` в ответе пустой.
- `captcha_vision_reasoning_effort: "none"` отключает режим рассуждения у моделей
  с reasoning (например, Yandex Qwen3.6): для капчи он не нужен, ответ сразу
  приходит в `content`. В логах при пустом ответе пишется `finish_reason`.

## Конфигурация (`config.yaml`)

| Параметр | Описание |
|---|---|
| `articles` | подсказка для поля ввода; статьи из окна имеют приоритет |
| `region`, `city` | география поиска |
| `court_type` | тип суда (`Мировой судья`) |
| `districts` | `[]` = все участки г. Перми; иначе список номеров участков |
| `lookback_days` | за сколько последних дней искать (плюс будущие заседания) |
| `scraper.*` | headless, таймауты, паузы, предохранители |
| `scraper.retry_on_500` | авто-перезагрузка страницы при ошибке 500 |
| `scraper.max_500_reloads` | сколько раз перезагружать страницу с ошибкой 500 |
| `scraper.output_excel` | путь к Excel-файлу с результатами (`data/cases.xlsx`) |

## Структура

```
config.yaml        подсказка статей и параметры поиска
src/config.py      загрузка config.yaml + разбор списка статей
src/scraper.py     Playwright-скрейпер ГАС «Правосудие»
src/parsers.py     разбор карточек дел (тестируется без сети)
src/storage.py     SQLite: история найденных дел
src/gui.py         окно tkinter: ввод статей, таблица, открытие в браузере
src/main.py        запуск
tests/             юнит-тесты (pytest)
```

## Ограничения

- Скрейпинг зависит от текущей вёрстки портала; при её изменении может потребоваться
  правка селекторов в `src/scraper.py` (есть debug-режим и скриншоты).
- Парсер выдачи проверен юнит-тестами на типовых таблицах/карточках; реальные селекторы
  формы поиска нужно один раз проверить на машине с доступом к `sudrf.ru`.
- Программа рассчитана на личное использование и вежливо обращается к сайту
  (случайные паузы между запросами). При появлении капчи поиск прерывается с
  сообщением — откройте портал вручную в браузере.
